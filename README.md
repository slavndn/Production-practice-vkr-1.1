# СПИСОК ИСПОЛЬЗОВАННЫХ ИСТОЧНИКОВ.docx

Приложение к отчёту по производственной практике: библиографический список источников, на которые опирается отчёт и разработанный прототип электронного журнала физической культуры.

## Содержание

В документе **18 позиций**, оформленных по **ГОСТ Р 7.0.5-2008**:

| Группа | Примеры источников |
|--------|-------------------|
| Нормативно-правовая база | ФГОС, СанПиН 1.2.3685-21, ФЗ № 273-ФЗ «Об образовании» |
| Органы и платформы | Минпросвещения (ФК), «Сферум», «Дневник.ру» |
| Методическая литература | Кузнецов В. С.; Лубышев Л. В., Мочалов Н. И. |
| Разработка приложения | Flask, Python, JavaScript, HTML, JSON (RFC 8259), Web Storage API, WCAG 2.2 |
| Развёртывание (справочно) | Gunicorn, nginx |

Электронные ресурсы снабжены URL и датой обращения (апрель–май 2026). Печатные издания указаны с выходными данными (место, издательство, год, объём).
